在 GT 8px 邻域 S8 内比较「每图最优阈值」：网络概率 vs 原图特征（GT 用于选水平与支撑域 → 上界性质）。
| S8 内 Dice | lesion1 | lesion2 |
|---|---:|---:|
| 网络 全局阈值 | 0.851 | 0.804 |
| 网络 每图最优阈值 | 0.870 | 0.852 |
| 原图平滑强度 σ2 | 0.733 | 0.818 |
| **背景归一化超额荧光**（σ2 − σ32） | 0.789 | 0.844 |
| 同上，每连通域独立水平 | 0.812 | **0.847** |
- lesion2：单一图像等值线即超过网络全局阈值 4pp；背景归一化是关键（+2.6pp vs 原始强度）。
- 无监督「iso-snap」（用模型自身轮廓估水平）无效甚至掉点 → 水平必须**学习且空间变化**。
- 全局统计量 kNN 预测每图阈值（CV）：macro 0.7850 < 全局 0.7904 → 负结果，水平不能由全局特征给出。
- 全验证集像元 AUROC：超额荧光 GT vs 8px 邻域 lesion1 0.749 / lesion2 0.819；血管脊 0.584 / 0.667。

## 3 方法：Photometric Level-Set head（`src/bs/photometric_levelset.py`）
z(x) = up(b)(x) + up(a)(x)·F(x) + up(c)(x)·V(x)
- F：全分辨率背景归一化超额荧光（染料浓度代理，增益/偏置不变）；V：Frangi 型亮脊（血管）响应，抑制各向同性局灶渗漏。
- a≥0（softplus，单调先验：超额荧光越高越可能渗漏）、c 由 1/4 分辨率解码特征 1×1 卷积给出并双线性上采样 → 决策边界 {z=0} 即 **F 的空间变化学习水平等值线**：F = −(b + cV)/a，可导出「水平图」解释。
- 参数 770 个（D=192,C=2,G=2）；非单调版零初始化严格等于 baseline；不改 baseline checkpoint 键。
- 测试 `tests/test_photometric_levelset.py` 8 例（增益不变性、线/斑选择性、等值线性质、初始化等价、键兼容），连同回归 29 passed；真实 768 批冒烟 bs4 峰值 6.1GB。

## 4 与既有物理先验线的关系（论文叙事）
RDH/VA-RDH 建模**染料输运**（源点+各向异性扩散），PLS 建模**观测/标注**（标注者在超额荧光上画等浓度线）。二者构成「成像 → 输运 → 标注」的物理可解释链条，PLS 对应其中边界放置这一实测主瓶颈。
