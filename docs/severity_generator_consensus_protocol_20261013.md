# 七生成器等权共识与假设分歧：开发实验协议

## 开发背景与评价边界

已查看原生成器敏感性及多征象结果：不同生成器的联合校准面积rho为0.5131–0.7524，病灶2信号不同；拟合集七个单位方向的最小cosine约0.335–0.374，有效秩约1.69–1.75。新候选由这些开发结果启发，不能称整个研究预注册，也不是新的独立确认集。掩码仍不进入任何拟合或候选权重。

不更换先前原生成器主方法，不选择已知面积rho最大的生成器。全部既有七种生成器原样使用：baseline、narrow、broad、single、many、half_dose、double_dose。均读取已经冻结的seed42联合gamma校准状态；不新增生成器、rank、权重、sigma或剂量搜索。

## 三种固定聚合

每个旧折、每个main/registration_group_stress scope有七个拟合集单位方向d_m、共同原图L2/StandardScaler变换z，以及各自的拟合集CDF F_m。必须验证七个scaler及拟合样本数相同，输入状态哈希匹配旧manifest。

1. **单位方向等权均值**：d̄=normalize(Σd_m/7)，raw=zᵀd̄。
2. **分位秩等权均值**：raw=ΣF_m(zᵀd_m)/7。
3. **分位秩中位数**：raw=median_m F_m(zᵀd_m)。

每种聚合的经验CDF和25/50/75分位点只用拟合原图raw拟合，再给保留原图及gamma0.8/1.2输出连续分位秩和0–3候选层级。全部三种聚合保留，不按评价结果选“最佳”。共有3×2×5=30个新聚合状态，2,055图×3条件×3方法×2scope=36,990条预测。

方向均值是非负等权组合；三种聚合均保留七坐标一致的弱偏序，但不保证真实疾病进展或每幅合成变化单调。三个候选对全部七种已固定生成器的保留低/高剂量另测严格两步单调率，报告所有结果。

## 保留生成器分歧

对每幅图保存七个原有CDF分数和层级，以及min/max分位秩、分位秩range、min/max层级和是否全部七生成器层级相同。层级一致时记录其共同候选层级；不一致时记录−1，表示生成器假设存在分歧。共识聚合仍给全部图像分数，分歧标记不替代原主方法。

min/max是已测试七种假设的输出范围，不是概率置信区间、临床等级区间或涵盖全部真实荧光过程的界。模型一致不能证明医学正确。预先固定range分组[0,0.10)、[0.10,0.25)、[0.25,0.50)、[0.50,1]，以及全部层级一致/不一致两组；不按面积结果调整边界或覆盖率。

## 冻结、重载与评价

拟合程序不能读取`mask_burden_evaluation_only.csv`。所有30状态重载，全部原图及gamma分数和层级逐条复算；七个输入状态的全部保留分数另与旧生成器冻结CSV匹配。保存真实折成员、源文件/协议/输入/状态/预测哈希之后，单独评价程序才读取掩码代理。

报告main及registration scope的面积rho、折间结果、图像bootstrap1,000次CI和与原生成器的配对rho差；辅助病灶2存在性AUROC、阳性内部面积rho、控制病灶1秩后的partial lesion2 rho；gamma秩/层级一致性；原生成器及全部七假设的层级分歧和固定分组代理结果。分组是描述性开发分析，不能称患者独立选择性临床性能。对面积差至少0.01的同旧折图像组合，另报告七假设全同方向的比例和正确面积方向比例，不按组合数计算独立样本区间。
