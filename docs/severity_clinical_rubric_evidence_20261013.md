# 血管炎评分全文与待确认临床终点

本补充实际阅读Dhirachaikulpanich等2023血管炎评分全文的Methods、Results及Discussion，扩展此前仅核对Crossref摘要的范围。原文为[PMC10442128](https://pmc.ncbi.nlm.nih.gov/articles/PMC10442128/)，DOI:10.1097/iae.0000000000003838。本文件只整理已有临床证据及对本研究的限制，尚未获得医生确认，不修改既有模型锁定、空白评分表或等待rubric状态。

## 原文中决定终点含义的细节

该研究来自Liverpool单中心，50位成人患者99眼；每眼选两幅WFFA，由两名葡萄膜炎专家、一名受训图像grader及一名住院医生独立评分，另有同一grader间隔一个月重复评分。使用105/150/200度成像，患者可有双眼，统计用GEE处理眼间相关。它不是对99幅任意单图按全图亮度或面积分四分位。

原文把血管渗漏称为活动度（activity），把闭塞称为损伤（damage），两者分别分级。中央区是以中心凹为圆心、中心凹到视盘鼻侧缘距离为半径的圆，中央区和周边区各分四象限。临床中央区不同于本研究按亮度启发式获得的FOV，不可互换。

| 维度 | 原文规则 | 对本地任务的限定 |
|---|---|---|
| 渗漏定义 | 血管来源的进行性高荧光，晚期面积向外扩展；不扩展的staining不计为活动性血管渗漏 | 单幅FA及gamma变换不能证明真实时间扩展，需真实早晚时相 |
| 渗漏L0–L4 | 无血管渗漏L0；只累及周边1–2/3–4象限为L1/L2；中央1–2/3–4象限为L3/L4，中央受累等级不依赖周边是否同时存在 | 规则同时依赖解剖位置和范围，不是总面积四分位；不能把本地0–3重命名为这些等级 |
| 闭塞O0–O4 | 按周边/中央、无灌注面积小于/大于3个视盘面积分级 | 本地两类掩码没有已确认闭塞定义，不能由渗漏分数反向推断；原文小于/大于的表述未明确恰等于3时如何处理，需专家规范 |
| 排除项 | RPE来源渗漏、视盘渗漏、新生血管和仅黄斑囊样水肿高荧光不纳入该RV血管渗漏维度 | 这些征象可能仍与其他葡萄膜炎终点有关；RV特定活动度不等于整体葡萄膜炎严重程度 |
| 可判读性 | 无法可靠评价血管渗漏/灌注，或可见少于两个象限时ungradable；可判读质量另记poor/fair/good | 本地真实视野及象限覆盖未知，不能自动套用WFFA量表 |

原文四grader渗漏ICC为0.655，闭塞ICC为0.750；两位专家之间渗漏ICC为0.795。视盘渗漏的观察者间kappa仅0.293，CMO为0.638；有OCT的82眼中，WFFA与OCT对CMO的kappa为0.444。渗漏分级与当前和1年视力相关，但闭塞分级的该关联未达显著。原文仍把闭塞作为独立的重要损伤维度，不能根据一个临床终点未显著就删除它，也不能由较好的总面积rho推出两个维度均有效。

原文存在量表分布不均，L4占其相应分析96眼中的37眼；L0占13眼，O0最常见。99眼入组与96眼该分析的分母不同，不能把不同分母混用。相关系数、ICC和kappa衡量不同对象，不能将这些文献一致性数值作为本地模型准确率。

## 需要医生/来源确认的事项

本地研究继续使用“无人工严重程度标签的FA炎症负担排序”，主要结果为图像级面积代理。来源应提供真实patient_key、眼别、采集session/sequence、时相、设备、视野/解剖覆盖及掩码版本/标签字典；跨折配准分量不能替代这些字段。双眼、多个视野和多个时相应保留关联，不能仅给每幅图像生成独立编号来声称患者隔离。

临床专家需要确认本地单幅图像能可靠评价哪些征象、是否有足够视野和真实时间信息、最终终点是血管渗漏活动度、闭塞损伤、多征象总负担还是整眼评分。若仅能对单图给出相对负担，应明确标注此层级，而不套用需要WFFA和时相的整眼规则。真实随访活动变化与横断面严重程度也须分开。

既有临床计划允许not_comparable和ungradable、逐医生单独评价、不使用医生标签选seed或改方向。该计划仍适用；本补充没有创建已批准rubric、真实等级或医生共识。空白`metadata_crosswalk_template.csv`列出了待确认字段，仅作数据交接说明。收到真实规范和来源关联后，才能在医生评分开放前冻结适用的终点、排除/缺失规则及患者级统计范围。

公开的评分示例图适合说明规则，不能取代完整原病例和独立评分，也不应从论文中的高/低例图构造“外部严重程度金标准”。外部数据的实际访问状态与限度见[来源可行性报告](severity_external_validation_feasibility_20261013.md)。
