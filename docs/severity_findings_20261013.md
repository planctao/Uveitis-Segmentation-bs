# 无人工定级标签严重程度研究：阶段实验证据

已完成文献核对、原始图像审计、八种无监督基线、合成校准及机制控制，以及DEC/AE、SwAV/VICReg三种子完整训练与评价、配准关联、生成器敏感性和等权共识。原固定联合主候选与人工病灶并集面积的图像层面保留折相关性为 **Spearman 0.7121**；生成器敏感性出现更高和更低的值，未据其最大值替换主方法。这不是医生严重程度分级准确率，也不是患者独立临床验证。CCF-B毕业论文目标保持进行中。

## 数据审计改变了评价集合

- 2,459幅图像，排除270幅`_aug`增强图，保留2,189幅原图。
- 67组相同像素图像跨越旧折，每组掩码均不同。病灶并集Dice范围0.3541–0.9921，中位0.8585；面积绝对差最大0.03746。主分析排除全部134幅重复组图像，剩2,055幅。

## 生成器敏感性：gamma稳定仍不足以确定病情尺度

在新变化的代理评价前固定六种单因素变更：sigma缩小/扩大、场数1/6、剂量减半/加倍。保留原三个Gaussian的共同随机中心和尺度随机数；额外场使用独立uid随机流。每种场集合仍归一化最大值，因此场数/尺度变化同时影响积分荧光量，不能解释为形状的纯因果效应。

原生成器及六种变化，分别在main和registration排除划分以seed42重新拟合四种原校准方法，共280个状态、345,240条冻结预测。所有状态重载核验、协议/缓存哈希通过。新生成器baseline在固定前8图与原函数逐像素一致；baseline全部main/stress输出另与已有结果全量复算对应。

所有联合方向对gamma的秩一致性仍超过0.9978，gamma层级改变2.73%–4.82%，而生成器之间的层级改变可达38.39%。因此，现有gamma去混杂测试不能证明对合成假设稳定。减半剂量的保留合成两步单调比例反而由84.2%降为73.9%；加倍剂量单调比例升到91.2%，面积rho却下降。这些现象不支持用合成单调成功率直接选取真实病情方向。PC1对这些变化保留相同符号，因此rho不变；这是数学方向稳定，不证明临床有效。

均亮度匹配量化前误差低于4.5e-16，六种变化量化后最大误差0.001632。registration排除结果和main非常接近，仍因仅追加排除两幅拟合图像。全部方法、各折、配对差和gamma结果位于`generator_sensitivity/evaluation/`。主方法继续使用原生成器；未来任何基于当前敏感性的新选择都属于进一步开发，需新患者级/外部确认。

## 后验多征象和失败诊断

固定seed42主候选按拟合图像亮度四分位点分档，保留图像union rho仍为0.6947–0.7211；亮度基线在相同档内为0.0750–0.2140。但主候选在控制lesion1面积秩后，partial lesion2 rho仅0.0195，再控制亮度为0.0235；PC1对应0.3333/0.3454。单标量主要覆盖占比更大的病灶1，多征象临床能力仍未建立。

三种子SwAV的全部45折输出均已重载，包括prototype的合成排序、拟合集经验秩及四分位边界，最大秩误差1.11×10⁻¹⁶。seed42相对原DINO的raw covariance有效秩由27.86–28.75降至1.49–2.67，坐标std保留原始1.34%–20.66%；其f4硬分配几乎全部指向同一个prototype。hard非空prototype数18/3/5/2/5，而soft mass有效数13.72–36.53；不将Sinkhorn平衡等同于最终hard占比。其余种子的完整表征诊断和所有不利结果均保留。

## 七生成器共识及选择子集的控制
