# 外部FA渗漏代理转移的预先锁定规则

本协议在未取得Duke原图、文件目录或外部标注时制定。既有本地面积开发结果已知，因此它不是整个研究的前瞻性预注册。任务是检验冻结排序在跨疾病FA上的渗漏代理转移；Duke DME不是葡萄膜炎严重程度队列，不能据其面积评价宣称临床定级有效。

## 已固定的推理规则

主分数使用既有临床锁定所指定的`registration_stress/seed42`联合gamma方向，五折状态全部使用；不增加本地训练，不根据外部结果选折、改方向或更换seed。四个明确开发对照是相同registration排除状态的局部合成方向、均亮度匹配方向、合成定向PC1，以及`baselines/seed42`的均亮度。这些对照的本地训练集合不完全相同，须披露；不把差异归为单一因果效应。领域SSL、C4与显著性不自动加入本次候选名单，既有结果继续保留。

每个输入经过与归档特征一致的RGB转换、双线性256×256缩放、8-bit量化和ImageNet标准化，以原始预训练DINOv3 ConvNeXt-Tiny提取特征。GPU采用原缓存相同的float16 autocast；CPU模式会记录数值差异，不能冒称位级复现。所有state、权重、推理代码和本协议哈希记录在独立`external_transfer/model_lock_manifest.json`。该锁不覆盖或修改既有临床锁定。

每折用其本地拟合CDF输出0–1分数，外部主输出是五折CDF分数的等权算术平均，不直接混合不同折的raw值。不在外部重新拟合StandardScaler、PCA、方向、CDF或阈值。五折raw、CDF、原本地分位层级、折间范围/SD和CDF饱和数全部保留。外部平均分数没有新定义的临床等级或四分位；外部新增/移除病例不得改变其他病例分数。gamma 0.8/1.2只作固定采集敏感性对照，原图gamma1.0为主条件。推理程序只接受`uid,image_path`两列，不读取掩码、患者键或评分。

本地实现验证必须覆盖完整2,055图×3条件×5方法×5冻结折，并与每图原所属测试折的冻结预测核对。多折应用本地图像时，除所属测试折外的模型可能见过该图；故全五折聚合只用于实现验证，不是新的本地held-out性能，禁止计算新的本地目标增益。另以固定原索引前8图检查原图到特征到预测的链路；这些图与归档缓存的重合必须明确记录，不能写为外部验证。

## 数据取得后的适用性检查

目前官方来源说明24眼/24患者、早晚时相FA视频/合成图和两名专家分割。允许研究/教学使用并要求引用Rabbani等IOVS2015，禁止商业化或再分发；原始数据与论文图片不能混为一谈。不注册账户、签署协议或主动联系作者。所有下载、许可及失败响应留存，下载成功前不得写已取得外部队列。

取得文件后先只核对文件清单和来源说明。必须从作者文档确认病例/患者单位、早/晚图、原图与合成图、人工grader1/grader2/重复grader和自动结果的对应关系；不能仅凭猜测文件名建立患者键。人工分割必须可无歧义恢复成与输入对齐的区域；若只有渲染边界、压缩叠加图或不清楚颜色/ROI，先报告不适用，不任意填充边界构造金标准。作者自动分割不得混入人工参考。

全部外部图按本地RGB像素哈希公式与全部2,189原图比较；记录外部内部完全重复。相同患者的早晚/序列帧、人工标注副本和同图合成版本不当作独立患者。无完全重复不能证明无同患者关系，须依来源文档。来源确认和纳入列表在读取目标数值前写入新的、追加式`cohort_lock_manifest.json`；若不能确认，终点仍为等待而非执行。

若每病例提供无叠加的晚期合成图及可恢复的两grader掩码和1500μm半径ROI，则以该晚期合成图每病例一项为主输入，以两名grader各自ROI内面积比例的算术均值作为主面积代理。两grader、重复grader、全图分母分别报告为预先声明辅助终点，自动分割只作来源记录。若该组合不成立，协议不自动改用有利图/标签；可在目标开放前追加新适用性方案，须披露变化。早期输入与同一病例晚期参考只用于时相依赖分析，不把其相关性解释为早期图真实泄漏程度。不能转移本地lesion2定义、黄斑1500μm物理ROI或合成荧光剂量为临床意义。

适用病例必须全量进入主评价；技术失败逐例记录并保留，禁止按排序/面积或“清晰度”事后删病例。最多预期24患者并不能证明文件包含完整24，实际数量以来源核对为准。若不能恢复所有患者，报告缺失和选择限制；不能称独立完整队列已验证。

## 外部统计与结论边界

先保存全部推理输出与哈希，再由独立程序读取人工标注。主统计为患者单位Spearman rho（原图条件、主分数、两grader平均ROI比例），辅助报告Kendall tau-b、每名grader的rho、折间敏感性、每个固定对照的rho及与主分数的配对差。患者bootstrap固定seed20261013、10,000次共用采样索引；各次保持该患者所有时相/grader记录一起。常数样本导致未定义统计时报告次数，不替换为0。若病例数太小或常数目标，不输出虚构区间。

报告CDF端点饱和、唯一值和ties，区分迁移失效与目标范围不足。24患者的区间仅覆盖患者抽样，不包含训练和本地开发选择。辅助对照多重比较不作未经修正的确认性优越结论。DME面积、时相和ROI与本地不同，禁止将两队列合并rho或给出葡萄膜炎严重程度准确率。

当前本协议锁定的是模型和推理实现，未锁定真实外部队列或确认其可评价性；`external_validation_performed=false`。医生评分rubric、本地真实患者关联和葡萄膜炎临床外部评价仍是论文必要缺口。
