# 合成荧光生成器敏感性：结果前冻结协议

本阶段已知原始生成器和DEC代理终点结果；以下六种变化的掩码评价尚未计算。此实验属于同一开发队列上的敏感性分析，不是独立确认，也不根据结果挑选更高rho的生成器替换原主方法。

原始生成器在256网格内使用三个Gaussian场，sigma8–24、低/高剂量0.08/0.16，配套均亮度匹配控制。固定一次仅改变一个因素：

| 名称 | 场数 | sigma范围 | 低/高剂量 |
|---|---:|---|---|
| baseline | 3 | 8–24 | 0.08/0.16 |
| narrow | 3 | 4–12 | 0.08/0.16 |
| broad | 3 | 16–48 | 0.08/0.16 |
| single | 1 | 8–24 | 0.08/0.16 |
| many | 6 | 8–24 | 0.08/0.16 |
| half_dose | 3 | 8–24 | 0.04/0.08 |
| double_dose | 3 | 8–24 | 0.16/0.32 |

保留原uid生成的前三个中心和sigma随机数；single保留第一个场，many额外三场使用uid加`:extra`独立确定性随机流。narrow/broad仅改变原三个场的sigma尺度；剂量只改变剂量。每个场集合仍以自身最大值归一化，总平均荧光量随场数/尺度变化；本实验不能隔离形状与总积分光量的效应。控制图继续匹配对应高剂量图的量化前视野平均增加。

全部2189原图使用原始冻结DINOv3权重提取新低/高/控制三种特征。baseline直接复用已有合成缓存；首先在固定前8图验证新生成函数的baseline与原函数逐像素一致。不开训练，不读取分割checkpoint或掩码。

固定seed42，在原main五折和registration_group排除五折分别重新拟合四种原始校准方法：局部方向、均亮度匹配、均亮度匹配加gamma前8维正交投影、合成定向PC1。每种变化只使用对应拟合图像的scaler、方向、PCA及四分位边界。预测和源码/协议/缓存哈希全部冻结后才加载mask代理终点。

所有生成器和方法都报告union面积rho、每折rho、lesion2存在性AUROC、gamma秩/等级稳定性、保留合成两步单调比例与均亮度控制响应。相同图像对不同生成器的rho差采用配对图像bootstrap1000次，报告完整范围，不以最大值作为独立性能。先前主方法保留原生成器；若后续开发修改生成器，必须重新取得患者级或外部确认。
