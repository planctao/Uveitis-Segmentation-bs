# PLS 区块级分割评价方案

日期：2026-10-21。用途：在像素 Dice 之外，回答“病灶有没有找到、数量是否接近、位置和面积是否大致正确”。两类病灶分别计算；此方案不把区块评价等同于已经经过医生验证的临床终点。

## 1. 区块定义与散点过滤

- 二值掩码按 2D 八邻域提取连通域，先排除 ignore 像素。
- 默认只保留面积 **≥50 px** 的区块，GT 与预测使用相同过滤规则；同时报告 30、100 px 的敏感性结果和被过滤的区块数、像素数。
- 面积与距离都在当前 **768×768 评价网格** 上计算，不能直接当作原图像素、毫米或视网膜实际面积。换分辨率时，面积阈值应按缩放比例的平方调整。
- 不默认膨胀、闭运算或填洞；这些操作会改变区块定义并掩盖合并、碎裂问题。

## 2. 一对一匹配

GT 区块为 G，预测区块为 P。首先构建满足匹配条件的候选边，随后求“命中区块数最大，其次总 IoU 最大”的一对一分配。

**检测规则**：IoU(G,P)≥0.10，表示大致定位到同一个区域。额外报告 IoU≥0.25、0.50，观察对边界一致性要求提高后的表现。该 IoU 是两个区块之间的重叠率，不是整张图的像素 Dice。

**大致一致规则（approximate，暂定）**：同时满足：

1. IoU≥0.10；
2. 0.5≤预测面积/GT 面积≤2；
3. 两区块的几何质心距离 d≤max(sqrt(GT 面积/π), 10 px)。

第三项允许的距离随病灶尺度变化；10 px 是小区块的最低位置容差。这里的 0.10、2 倍、1 个等效半径、10 px 都是显式、可调整的工作定义，不是医学上已确定的标准。应与医生按应用目的确定容差，再在独立数据上使用。

一块预测覆盖多个 GT 时，最多匹配其中一块；一个 GT 被预测成多块时，也只能匹配其中一块。其余计作漏检或误检，并另报合并、碎裂数量。

## 3. 推荐同时报告的指标

| 方面 | 定义 | 用途 |
|---|---|---|
| 数量 | 每图 GT 数、预测数；平均绝对误差 mean(abs(Npred−Ngt))；有符号偏差 | 是否经常多分或少分 |
| 区块召回 | TP/(TP+FN) | 应找到的病灶有多少被找到 |
| 区块精确率 | TP/(TP+FP) | 预测病灶有多少可对应 GT |
| 区块 F1 | 2TP/(2TP+FP+FN) | 同时约束漏检和误检 |
| 大致一致召回/F1 | 将匹配条件换成 approximate | 同时要求位置与面积大致合理 |
| 质心距离 | 已匹配区块质心的欧氏距离；报告 px、距离/图像对角线、距离/GT 等效圆半径 | 找到后，位置误差有多大 |
| 匹配区块面积误差 | abs(Apred−Agt)/Agt；另报带符号误差和面积比 | 找到后，面积是否接近，以及偏大还是偏小 |
| 每图总面积误差 | abs(ΣApred−ΣAgt)/ΣAgt，仅 GT 总面积>0 时定义 | 包含漏检、误检后的总病灶负荷误差 |
| 阴性图误检 | 无保留 GT 的图像中，误检区块数/图，以及出现误检的图像数 | 防止大量阴性图掩盖误检 |
| 合并/碎裂 | 若交集覆盖较小区块至少 10%，视为有重叠关系；一块预测连接≥2 个 GT 为合并，一个 GT 连接≥2 块预测为碎裂 | 解释数量错误的来源 |

**数量接近不代表找对位置。** 两边各有三块但位置完全不同，数量误差为零，区块召回仍为零。

**质心/匹配面积误差必须和召回一起读。** 它们只评价已匹配区块，漏掉难分病灶可能使平均距离看起来更好。approximate 本身限制了距离和面积，故应同时看未加面积/质心限制的 iou10 结果。

无 GT 的图像不定义召回，无预测不定义精确率，双方都没有区块不人为记 F1=1。总体 precision/recall/F1 用所有图像的 TP/FP/FN 汇总计算，阴性图上的误检仍进入分母；逐图平均与五折平均不能混称为总体汇总值。

## 4. 当前实验读取与统计

复用 `outputs/seg26_eval_cache/f1..f5` 中 Control、PLS 的 best.pt 四向 flip-TTA sigmoid 概率、target 与 valid。Control+PLS 是两模型 sigmoid 概率的 float32 算术平均，不重新训练、不修改数据集。

固定 0.5 阈值用于直接比较；另报告现有各折、各类别 Dice 扫描选出的阈值，以对应此前实验。后者仍是验证集内选择结果，不能称为独立测试性能；当前 checkpoint 本身也经过验证集选择。

预先固定默认过滤面积 50 px，报告 iou10 的检测、位置/面积指标及 approximate 的联合一致性指标，保留全部敏感性结果，不依据哪个规则对 PLS 有利来选规则。

配对 bootstrap 对同一批图像重采样，差值方向为 PLS（或集成）减 Control。指标未定义时，仅保留双方均有定义的图像，并报告有效图像数；双方都有匹配也不意味着匹配的是同一批 GT。该图像 bootstrap 不处理同一患者多图的相关性，只作为描述性分析。

## 5. 代码与运行

- `src/bs/region_metrics.py`：连通域、几何量、一对一分配、每图评价与总体汇总。
- `scripts/evaluate_region_metrics.py`：五折缓存评价，输出 JSON 与 gzip 压缩逐图 JSONL。
- `scripts/summarize_region_metrics.py`：从完整结果生成中文结果表与比较图。
- `tests/test_region_metrics.py`：空掩码、过滤、质心、面积、合并/碎裂、最大匹配、缺失配对与端到端缓存评价检查。

```bash
PYTHONPATH=src python -m pytest tests/test_region_metrics.py -q --basetemp outputs/region_metrics/pytest_tmp
python scripts/evaluate_region_metrics.py
python scripts/summarize_region_metrics.py
```

默认输出 `outputs/region_metrics/paired_control_vs_pls_20261021.json`，其中每种规则均有各折和全部五折汇总。对应 `_per_image.jsonl.gz` 保留每张图的数量、匹配及几何指标，图像以 `(fold, cache_image_index)` 标识；原缓存没有保存文件名，不推测患者映射。

## 6. 2026-10-24：按用户要求允许合并与碎裂

用户明确“两块 GT 合并成一块以及一块被分成四块都算正确”。新增独立的 GT 区块覆盖召回，保留此前的一对一结果供比较。

对每块保留 GT `G_i`，设 `P` 为所有保留预测块的并集：

`coverage_i = |G_i ∩ P| / |G_i|`

`Recall(t) = sum_i(coverage_i >= t) / GT区块总数`

同一个预测块可使多个 GT 命中，一个 GT 可被多块预测合起来命中，每个 GT 最多计一次。两边仍先按 50 px 过滤散点，附 30/100 px 敏感性；被过滤的预测碎片不参与联合覆盖。

同时报告 t=0.10、0.25、0.50，分别表示宽松检出与不同程度的区域覆盖。它们是 GT 覆盖率阈值，并非 IoU 阈值。另报任意预测块与 GT 的 IoU≥0.1 即命中的召回：该对照仅取消一对一限制，仍会因大合并块或小碎片的面积而降低 IoU。

不对单个预测块继续使用面积比和质心门限，否则会重新处罚被允许的合并/碎裂。覆盖召回也不约束 GT 外的多分区域，必须结合原来的误检和总面积误差阅读；完全涂满图像会取得 100% 覆盖召回。

运行 `python scripts/evaluate_merge_split_recall.py`，结果写入 `outputs/region_metrics/merge_split_recall_20261024/`。脚本复用原五折概率图、验证集阈值和连通域定义，保留逐 GT 覆盖率与逐图命中数。它校验各折 GT/预测数量与原报告完全一致，以及取消限制后的宽松召回不低于原一对一 IoU≥0.1 召回。
