# 外部FA评价数据的来源与可行性核对

本轮目的是推进真实患者独立和临床评价所需的数据证据，不根据已有面积结果开发或选择新主方法。上一轮C4实验及论文审计属于实质进展。本轮核对了公开来源、重新检查2189幅本地原图的标准文件头，并实际阅读全文中与临床终点相关的方法/结果/讨论。原主方法、临床锁定和只读数据集保持；没有取得外部患者图像或产生外部/医生评价指标。

## 本地临床信息的实际检查

对`data/images.csv`中的全部2189幅原图，PIL成功读取2189个文件头，未发生异常。观察到16种EXIF/TIFF字段，均为尺寸、像素编码、条带、压缩、分辨率等结构字段；没有观察到DateTime、DateTimeOriginal、ImageDescription、UserComment、GPSInfo等候选临床信息字段。图像info只包含JFIF、压缩、dpi、resolution、sRGB和gamma等键。检查记录只保存字段名及uid，不打印字段值。

遍历本地`dataset/`得到的非图像文件只有`.DS_Store`和既有掩码转换`summary.csv`。这些结果将“没有找到患者表”的依据扩展到现存标准图像头；不证明原医院系统没有患者关联，也不排除未提供的其他来源。不能据文件编号、相似图像、EXIF分辨率或图像背景推断患者、眼别、FA时相或视野。完整逐文件字段清单见`external_data_search/local_header_audit.json`。

## 检索范围与限制

检索日期2026-10-13 UTC。保留每次URL、状态码或连接错误、返回内容哈希及原始响应。Europe PMC的针对性title/abstract检索返回33条uveitis/vasculitis相关记录及76条FA数据相关记录，均在本次100条分页范围内；初始宽检索分别为581/4081条，仅取前100条。DataCite初始uveitis+fluorescein共83条，仅取前50条；FA Dataset检索共210条，仅取前100条。GitHub fluorescein检索29条。Zenodo第一次组合请求400，改用uveitis单词后200、318条中取前20条。结果涉及文章、补充图表、病例和动物研究，不能按搜索命中数计算可用临床数据集数。

这是有记录的可行性检索，不是系统综述或穷尽性证明。没有检索到直接可用的真实葡萄膜炎严重程度原始队列，不代表世界上不存在这类数据。公开摘要、代码仓库和文章开放许可亦不能自动证明原患者图像已公开或具有相同许可。

## 对后续评价的具体影响

Duke DME是本轮定位最明确的可用原始FA候选。访问恢复并核对文件后，可在读取标注之前冻结外部检验方案：使用原锁定模型的固定五折输出聚合，禁止外部重拟合、用其面积选择方法或改符号；按原24患者病例单位报告，区分早晚时相及作者合成图，医生分割分别评价，并核对本地像素/文件重复。其黄斑1500微米ROI和DME标注定义不同于本地全图union，因此必须单独称跨疾病渗漏代理转移，不能横向合并rho或当作外部葡萄膜炎定级准确率。当前没有文件，因此这些步骤尚未执行，不能写成完成的外部实验。

临床严重程度评价仍需真实患者/眼别/时相/视野关联和专家确认的rubric。新读全文对渗漏活动与闭塞损伤的区分及本地单图限制见[临床终点证据补充](severity_clinical_rubric_evidence_20261013.md)。`metadata_crosswalk_template.csv`只有表头、没有患者信息；用于列明待来源确认的字段，不是恢复出来的患者表。

可重运行本地审计：

```bash
OMP_NUM_THREADS=4 OPENBLAS_NUM_THREADS=4 python scripts/audit_severity_external_data.py
```

脚本不发起网络请求、不训练、不读医生评分；核验归档响应哈希、10行来源表、全部本地文件头和既有临床锁定。审计保持`external_validation_performed:false`、`clinical_grading_validated:false`及`goal_achieved:false`。
