# 基于图像血管结构的关联分组审计

本审计使用图像结构检查同眼/重复视野关联，不能恢复真实患者编号，也不把未匹配图像自动解释为不同患者。已有掩码代理结果已知，配准阈值在本审计结果计算前固定，不根据某个分组下rho最好来选择阈值。

候选对为冻结原始DINO的L2归一化特征30近邻，以及已有dHash≤4候选的并集，覆盖2189原图。使用512灰度网格、CLAHE clip2.0/tile8、ORB最多2000关键点、fastThreshold10。通过双向Hamming两近邻ratio<0.75的互相一致匹配筛选，至少40个good匹配后拟合相似性变换：RANSAC阈值2像素、2000迭代、confidence0.995。

确认关联须有至少40个inlier、inlier比例≥0.60、中位重投影误差≤1.5像素、变换尺度0.7–1.4、有效视野重叠占较小视野≥0.20，且配准后灰度的相关系数≥0.40。相关系数仅作为空间一致性辅助，不要求不同FA时相灰度完全一致。跨折完全重复对必须作为已知阳性核对召回，但不据该召回事后放宽阈值。失败原因全部保存。

图像关联对的连通分量只命名registration_group。它们可能对应同眼多视图、重复导出或某些错误匹配；不能命名patient_id。大型连通分量和跨折代表配对需要图示复核。未发现的关联、左右眼及无重叠视野仍需真实患者元数据。

后续registration stress沿用旧五折，但将与保留图像同registration_group的所有拟合图像排除，重新仅在剩余拟合图像上拟合冻结表征的合成方向及gamma子空间。保持原生成器、seed42/2026/3407与四个方法不改。该stress不替代外部测试；训练中的DEC/SwAV原预算完成结果仍明确标注为main划分，不将旧main训练state冒充registration排除后的state。
