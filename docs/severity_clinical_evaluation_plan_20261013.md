# 真实临床评分进入前的评价计划

已有本地盲法准备包含200图、100个随机不重叠配对和双医生空白模板。尚无真实评分，未向任何人发送。它来自当前开发队列，不能称外部验证，也未建立患者独立。本文不从掩码、亮度、模型分数或合成剂量生成“医生评分”。

## 模型锁定和评分规范

主候选保留原始冻结DINO、原合成生成器和均亮度匹配＋gamma前8维投影，seed42，使用registration_group排除后的保留图像分数。其源码、训练图像成员、scaler、方向、分位边界及预测文件均已有哈希。所有实际临床标签开放前保存锁定模型清单；后续SwAV/AE作为预先声明的辅助比较，固定最终epoch及seed42，不能按临床标签挑种子、调符号或更新生成器。辅助模型若在标签开放前尚未完成，不补作声称预注册的主要比较。

医生先确认单幅FA可评价征象、可比视野/时相、无法判读标准及共同rubric版本。四分位0–3不是临床四级，完整ASUWOG总分与SUN不能直接套在单幅图像模板上。ordinal等级值与描述必须在评分开始前有对应规范；目前这一临床规范未获得专家确认。原随机配对不保证视野和时相可比，允许not_comparable和ungradable。

医生独立评分，不看模型输出、掩码或另一医生结果。保留独立原始CSV、rater_id、rubric_version、评分时间及修改记录。patient_key、眼别、视野和FA时相仅从真实授权来源关联；如果缺少患者ID，不能把registration_group当患者ID。

## 终点和统计

主要临床终点为模型连续分数与每位医生单幅ordinal炎症等级的Spearman相关，分别报告两位医生结果、样本数、缺失和无法判读原因。不先平均等级形成不存在的“金标准”。比较使用同一有效图像集合，并完整列出剩余数据；评分分布及低变异情况另报。

配对排序为辅助终点：在每位医生明确A_more或B_more的配对中报告模型方向正确率，模型完全同分计0.5。医生判tie的配对单列模型分数差分布，不事后根据tie设最优阈值。not_comparable、ungradable和未评分分别计数。双医生一致与分歧配对分别描述；只展示一致配对的成功率不能替代全部单医生结果。

医生之间对可判读ordinal等级报告quadratic weighted kappa及原始交叉表，前提是共同rubric确有有序等级。对配对选择报告交叉表及一致率，区分不可比/无法判读与病情tie。医生等级一致性不是模型临床准确率；模型分位层级不直接和医生等级计算QWK，除非另设患者级校准和测试数据并公开监督使用。

置信区间固定bootstrap2000次、seed20261013。有真实患者ID时按患者resample；配对涉及两位患者时按配对bootstrap仅作为描述，并另报告患者复用/关联造成的限制。没有患者ID时保留图像/配对bootstrap并明确其局限，可额外使用已发现registration_group作敏感性，仍不称患者区间。两医生和多个辅助模型并列完整报告，不据最大值下临床结论。

图像旧折分别训练，分数为拟合集经验分位秩。跨折配对比较依赖分位校准可比的假设；须报告同折与跨折配对的数量及各自结果，不能忽略折间采集分布变化。现有100对每图只出现一次，但真实患者可能复用。

## 解释边界

医生评分只是该开发队列新获得的盲法终点，不能消除此前基于掩码的模型开发选择。方法若使用医生评分拟合绝对等级映射，必须另划真实患者级校准集合，并在未用于选择的患者级/外部集合验证。单幅排序临床有效，也不能自动推出整眼多视野、连续时相或治疗随访的严重程度有效。

当前此文件是一份待临床rubric确认的分析计划；尚未开始真实临床实验，不能称临床预注册已完成。

## 实际分析工具和标签开放前的补充声明

首个完整VICReg种子的面积开发结果已知，但真实医生模板仍为空。在读取任何临床等级之前，将VICReg最终epoch/seed42联合gamma分数补为辅助比较，与原定AE/SwAV并列；不依据临床终点挑选它或改主候选。四个模型和全部200图的分数将在`clinical_evaluation/model_lock_manifest.json`及`locked_scores.csv`锁定，主候选仍为registration排除后的原DINO。其他方法与其他种子不补入声称锁定的主要/辅助临床表。

图像表的`gradable`采用空白/yes/no；空白且无等级是未评分，yes且无等级是缺等级，no必须不含等级。任何实际判断行须填写对应A/B的rater_id和已确认rubric_version。等级使用医生确认的`ordered_levels`字符串，工具不默认指定0–3的临床含义。配对表的五类choice及空白分别统计。

`lock_severity_clinical_models.py`只在实际模板无判断/等级时运行；`evaluate_severity_clinical_review.py`核对锁定源码、预测及case/pair身份后，才读取评分。医生未确认rubric或没有真实填写结果时，输出等待状态，不计算临床性能。测试仅使用明确标记的数值构造，不写进医生模板。

截至本稿，锁定清单包含原DINO registration stress主候选、AE、seed42 SwAV和seed42 VICReg四个分数源；所有评分行仍为空，当前运行输出为`awaiting_clinician_confirmed_rubric`。这证明了评价边界和输入冻结，不是临床验证结果。

单医生统计使用其全部有效图像，同一医生下四模型在同集合进行配对比较。Spearman遇到不足三例或分数/等级恒定时报告未定义，bootstrap恒定重采样记为无效并公布有效次数，不把它们当0。提供真实完整病例patient_key/source_reference元数据时，对单图终点抽样整个患者簇且保留重复簇的重数；否则报告图像区间。这里只涉及评价200图的抽样，仍不能证明训练/保留折的全部患者隔离。配对区间仍按pair作描述，报告患者复用及同折/跨折、双医生一致/分歧子集，不能将它称患者独立置信区间。
