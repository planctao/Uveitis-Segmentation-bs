# 固定主候选的后验失败及多征象诊断

本分析在已知汇总代理结果后制定，是开发数据上的描述性错误分析，不是独立确认，不重新拟合或选择模型。固定seed42：registration_group排除后的原联合gamma方向和原合成定向PC1；原main均亮度基线；main预算匹配AE的gamma方向作为辅助。它们的预测先核对冻结哈希，之后才打开掩码评价。AE与亮度基线没有做registration排除，此划分差异明确报告。

按每个保留折对应的registration拟合集，计算图像平均亮度与启发式FOV占比的25/50/75分位点，将保留图像划入四档。分位点只使用图像描述量，不使用掩码；出现重复分位点导致空档时报告空档，不更换切分。另分别报告lesion2非空/空、图像文件格式的分组结果。文件格式只能作为可观察的数据来源相关量，不作为患者或设备编号。

各分组报告样本数、union面积rho、lesion1/lesion2面积rho，以及有两类样本时lesion2存在性AUROC。不以某组成功率调模型。置信区间使用图像bootstrap1000次、seed20261013；小于20例或目标无变化时保留缺失/样本数，不强求有效rho。它们不能替代患者区间，也不做因果混杂结论。

在全部2055图像上另计算score与lesion2面积的partial Spearman：分别移除lesion1面积秩，以及lesion1面积秩加平均亮度秩的线性作用。此步骤仅对冻结输出进行评价统计，掩码不进入模型。同时报告lesion2阳性图像内部的面积rho，避免把存在与程度混为一个终点。

面积排序对采用同一旧折的全部图像组合，分别以union全图占比差≥0.002、≥0.01、≥0.05定义可判面积大小的配对。模型同分计半个正确；报告每折、每阈值的组合数和正确率。配对并非独立样本，不以组合数计算二项置信区间，也不称医生比较准确率。不同阈值均完整保留。

为检查失败形态，主候选score与保留折内union面积经验秩的差作为描述性残差。按残差排序分别展示最高6个正差和最低6个负差，uid作为稳定并列排序；并保存全体残差表。图中同时显示原图和两病灶/重叠调色板掩码。病例选择依赖评价掩码，明确属于后验示例，不能证明真实炎症过高或过低，也不判断标注与算法哪一个临床上正确。选中病例的解码掩码哈希须与既有评价表一致。
