## 原文范围、可视化及机制限制

原算法还包括图割、IPACHR血管分割、视盘去除和形态处理，本实验只适配显著性线索用于图像排序。scikit-image SLIC、灰度/Lab转换、[0,1]动态范围、密度归一化和近邻并列规则均有明确实现选择，原MATLAB细节未全部提供。因此不能将本表称为完整原算法复现，更不能据此声称TMI原文的临床分割结果错误。原文参数经过外部标注数据调试，继承参数只意味着没有使用本地掩码拟合，不意味着从未使用外部标签。

六幅按合格图像顺序均匀抽取的原图/线索图已实际查看；可见部分高响应位于视盘、血管及边缘。这与原论文需要后处理的说明一致，但不是病灶语义金标准或其失败原因的因果证据。该例图选择和计算均未读取面积目标，且全量计算没有据此改变参数。

![均匀抽取的显著性线索图](../outputs/severity_research_20261013/classical_leakage_baseline/illustrations/uniform_saliency_maps.png)

图2：六个固定图像的灰度输入、强度线索、紧致度线索和乘积图。显著图不是经过验证的渗漏掩码。

固定分区时，原Eq.(2)–(9)的绝对强度差在灰度反转下保持，强度/紧致度线索因此也保持。该数学对称性通过测试，说明显著性本身不提供亮暗医学方向；完整SLIC的Lab转换和分区可能随反转变化，不能外推为整幅算法必然不变。另三项测试覆盖区域编号与近邻并列语义、均匀图零响应及拟合秩并列。测试仅验证实现性质，不验证临床效力。
