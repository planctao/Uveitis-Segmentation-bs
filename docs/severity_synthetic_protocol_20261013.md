# 合成荧光方向校准：后续探索协议

这是在首轮八个基线产生负相关以后启动的探索实验。第一轮掩码评价已经读过，所有后续结果属于同一数据集上的方法开发，不能称新的独立确认集。第一轮方向及负结果保留；本协议不改写原协议，也不通过真实掩码面积选择方向或投影超参数。

## 可证伪问题

局部高荧光比例把清晰正常血管也计入亮区，第一轮图像先验未得到正向掩码面积验证。下一步测试：**能否用已知的合成局部荧光增加确定预训练空间的方向，并用均亮度匹配/亮度扰动对照区分局部变化和采集变化？** 合成方向成功仅说明该机制产生可用信号，不证明合成图像是真实炎症、也不证明模型已实现临床定级。

## 固定生成器

只读取图像。每幅图像依uid哈希固定随机种子，在256网格的启发式视野内随机选3个中心，Gaussian sigma在8–24像素均匀采样，合并并归一化到最大1，得到f(x)。两个剂量t=0.08/0.16生成 `I_t=I+t*f(x)*(1-I)`，视野外保持原图；8bit量化。另生成均亮度匹配的空间均匀增加：`I_control=I+c*(1-I)`，c取局部t=0.16增加总量/视野内剩余亮度总量，从而量化前的视野内平均亮度相同。该对照只匹配均值，不匹配纹理或完整直方图。

这属于无人工分级标签的合成自监督/机制校准，有生成参数提供监督，不称完全没有任何监督。发生局部增加的图像本身不成为临床轻重标签；真实时相、染色、视盘变化或血管病变均可能偏离该生成器。

## 四个固定比较

所有变换只在每个拟合折的原图及合成/扰动特征上计算，沿用原五折、完全重复组排除及近似组stress。预训练DINO冻结，先L2归一化并用拟合原图StandardScaler变换。

1. `synthetic_direction`：原图到t=0.16合成图的平均特征差作为单位排序方向，原图投影输出连续分数。
2. `meanmatched_direction`：t=0.16局部图与均亮度匹配控制图的平均特征差作为方向，检验局部变化是否比平均亮度重要。
3. `gamma_orthogonal_direction`：对两种gamma相对原图的拟合特征差做无中心SVD，取固定前8个右奇异向量；将第二个方向投影到它们的正交补，再归一化。报告保留范数及奇异谱，避免将删除病理信号误称去混杂成功。
4. `synthetic_oriented_pc1`：保持原图DINO第一主成分不变，只根据拟合原图→t=0.16合成图的平均PC1变化决定符号。它是合成方向的控制，禁止按掩码相关性翻转。

方向退化（范数<1e-10）或训练合成剂量响应不符合预期也要报告。所有层级沿用拟合分位点0–3，不赋予临床名称。报告拟合与保留原图→0.08→0.16的分数单调比例、均亮度匹配误差、gamma秩一致性、掩码面积相关及采集混杂相关。使用与原协议相同的图像bootstrap口径；新的实验在代码/协议冻结、排序输出保存以后才读取评价掩码。
