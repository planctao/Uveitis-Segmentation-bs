# 冻结主候选的方形图像几何扰动检查

本方案在已有面积代理与gamma稳定性结果之后制定，属于开发阶段的后验压力测试。问题是：局部荧光校准得到的固定分数是否依赖同一幅图像的方向。全部变换和输出在新压力测试结果计算前固定，不选择更好的生成器、seed、checkpoint、阈值或测试时聚合方法。

使用原DINOv3 ConvNeXt-Tiny预训练权重、原256×256 RGB双线性缩放与FP16/batch8推理。保留2189原图的缓存顺序，以复现原批次；仅2055幅未排除冲突重复组的保留图像进入评价。使用seed42、main五折的四个原合成校准器，各图只由其保留折对应的已冻结state评分；scaler、方向、经验CDF和25/50/75%切点均不重拟合。原临床锁定分数不修改。

在缩放后的RGB整数网格上执行完整D4群：identity、逆时针90/180/270度旋转、左右反射及其后90/180/270度旋转。它们是像素置换，无新增插值、裁剪、填充或亮度变化。各图各条件检查RGB像素多重集完全相同；全图病灶面积在同样的置换下由数学定义保持不变，无需打开或改写掩码。旋转和反射分别报告；反射可能改变解剖侧别，属于数学控制，不假定它是合法临床采集变化。也不把90度旋转等同于实际摄像机角度分布。

先严格核对原缓存、预训练权重、源文件、原冻结预测与20个state的SHA256。重新推理identity，报告与原缓存全部2189图的特征最大误差；四个校准器的2055图identity分数与原冻结main预测须匹配至1e-12且层级完全相同，否则停止并调查。原始解码图像的像素哈希须与只读图像清单一致。

阶段A只读图像和既有state，保存8条件特征、全部65760条分数/原始投影/层级，以及源码、协议、输入、状态和输出哈希，再生成冻结manifest。阶段B核验全部冻结哈希后才读取既有面积评价CSV。不能把先前已经查看过面积结果的本次研究称为未见标签的确认性检验。

报告四方法、八条件的pooled及每折分数秩一致性、分位层级改变、平均绝对经验秩改变、>=2级改变比例、全图union/lesion1/lesion2面积rho及lesion2存在性AUROC。面积指标使用同一图的原目标，因为完整方形网格置换保持全图面积；本实验不评价FOV归一化面积。另报告每图七变换的最大绝对秩改变、是否发生任何层级改变及三旋转/四反射分别的汇总，保存全体逐图明细，不按结果选择病例。

均RGB亮度为像素置换的精确不变量，报告其所有条件最大差值，作为程序负控制；它不被当作更好的疾病分数。union rho相对identity的配对差使用1000次图像bootstrap、seed20261013、全部条件共用索引；固定模型的图像区间不涵盖未知患者关联、重新训练或多候选开发选择。不以扰动通过率给模型新的临床名称，也不以测试结果选择新主方法。本轮不训练SwAV/VICReg，不修改任何数据集文件或原冻结模型。
