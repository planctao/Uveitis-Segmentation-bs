# 文献显著性线索的图像排序追加协议

这是已查看开发队列面积结果之后固定的追加开发对照，不是新的确认性评价。目的为加入直接相关FA文献的非学习图像线索，检验显著性与本地面积排序的关系；不按结果挑选方法、改变原主候选或临床锁定。

## 已实际阅读的来源与复现范围

Zhao等《Intensity and Compactness Enabled Saliency Estimation for Leakage Detection in Diabetic and Malarial Retinopathy》，DOI:10.1109/TMI.2016.2593725，2016在线、TMI 36(1):51–63，2017正式卷期。已取得Edge Hill大学公开作者稿，12页全文文本已阅读，并实际查看第4页公式。原文件和响应哈希位于`classical_leakage_baseline/literature/`；Cranfield和Edge Hill的部分URL返回403，不能把错误页当作PDF。

原方法用SLIC的333/666/1000超像素、compactness=10、sigma=0.2、alpha=15、beta=300、M=10，分别计算强度与紧致度显著性，同线索跨尺度均值后作Hadamard乘积。最终原论文还包括阈值0.65、图割、IPACHR血管分割、视盘去除和形态操作。本追加实验针对**显著性线索的图像级排序适配**，不声称复现完整渗漏分割器、原数据结果或患者临床定级。文中参数及阈值经过原标注数据调试，继承这些参数不等于它们从未使用过外部标签；本地不使用掩码或医生标签拟合/选择。

2015前作（PMC4450752）已检查方法与数据段，含人工测量视盘直径及125微米规则，本地没有这些来源字段。2020 CycleGAN相关工作的题目/DOI已核对，但未取得全文，不能凭摘要复现。本实验不以近似血管、视盘或早晚时相替换这些未知输入。

## 固定实现选择

1. 保持既有256×256网格：原图RGB双线性缩放，按既有gamma实现量化为8bit，再转PIL灰度[0,1]。每幅原图的解码像素哈希须与原审计一致。仅处理旧五折主分析的2055幅合格图像。
2. scikit-image 0.26.0 SLIC采用重复三通道灰度、标准Lab转换、compactness=10、迭代10次、sigma=0、启用连接性、start_label=0，其余参数在源码显式列出。原MATLAB SLIC版本、输入动态范围及迭代等细节未全部说明，因此此实现属于公开公式的适配，不能称逐像素作者代码复现。记录实际超像素数。
3. 按原稿Eq.(2)–(9)计算区域线索；KDE的H按超像素单元和归一化为1，坐标标准差采用总体标准差。强度近邻按区域均值绝对差；紧致度近邻按紧致度绝对差，均排除自身。原文未明确近邻边界并列的处理，本实现对边界全部并列者赋分数权重，使有效近邻数为M，并避免依赖超像素编号。记录这些确定性选择，不检索最有利设置。
4. 同线索的原值先跨尺度均值，再将两线索原值相乘；三张图分别按整图min–max归一化至[0,1]，常数图为0。有效视野只用于最后汇总，沿用既有最大非黑连通区启发式，不提供解剖视盘/黄斑信息。
5. 固定四种分数：强度图FOV均值、紧致度图FOV均值、乘积图FOV均值、乘积图大于0.65的FOV比例。面积越大/显著质量越高方向设为正，不用目标反转。每折只用其他四折原图分数估计经验秩和四分位点，输出0–3为相对分位层级。固定分区时，原公式对灰度反转具有对称性；该构造性质仅作机制说明，不先验保证显著性就是渗漏或临床活动。

## 冻结、评价和报告

完整生成identity/gamma0.8/gamma1.2，4方法×2055图×3条件=24660条预测。20个折内秩/阈值状态落盘并重载全量核对；源码、协议、图像清单、来源、像素哈希、分数及原临床锁定哈希在第一次读取本轮目标之前冻结。原主/均亮度分数使用已有冻结输出，不重新拟合。

评价覆盖四种方法的全部条件、五折与汇总。主报告为原图union面积Spearman及相对原主方法/均亮度的配对图像bootstrap差值；辅报lesion1/lesion2、lesion2存在性AUROC、亮度/FOV相关性，以及gamma秩一致性和层级改变。1000次图像bootstrap沿用固定seed20261013；无患者信息，区间不覆盖患者关联与开发选择。掩码仅在独立评价脚本读取，不进入显著性计算、阈值或方向。不会把阈值图命名为经过验证的病灶分割或把这些层级命名为轻中重。

均匀图零响应、固定分区亮暗对称、区域编号/近邻并列不变性和拟合秩并列语义先通过测试。资源探针仅看用时、内存、数值有限性和图像线索，不读面积目标；全量用CPU两进程、每进程单线程，保持既有分割训练队列运行。保留全部负结果，不以开发rho替换锁定模型。缺真实患者关联、医生rubric和外部评价，目标保持active。
