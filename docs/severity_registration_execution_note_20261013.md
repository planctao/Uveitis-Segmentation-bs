# 配准候选查询的执行偏差记录

在配准计算尚未结束、尚未评价registration stress的掩码相关性时，发现候选查询的一个计数偏差。原协议写30近邻，实际调用`NearestNeighbors(n_neighbors=31).kneighbors(X=None)`；库在X=None模式自行排除训练点本身，因此返回31个其他图像，而不是30个其他图像加自身。

本轮保留已启动的31近邻候选审计，完整报告实际候选数62,673，不将其称为30近邻执行。它增加了候选覆盖，所有几何/光度确认阈值、mask-free要求及最终stress方法保持原预设。没有根据严重程度或掩码指标选择31，也没有据初步配对结果放宽确认阈值。该偏差及实际源码供复现者检查；这是探索性分组审计，不能表述为严格无偏差的预注册执行。
