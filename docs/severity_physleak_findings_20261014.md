# PhysLeak: Counterfactual Difference Probe（CDP）无监督 FA 渗漏负荷 —— 实验记录（2026-10-14）

## 1. 动机
10-13 的全局方法（DINOv3 CLS + 合成高斯方向 + gamma 正交投影，pooled ρ≈0.712）只能给出一张图一个分数，
lesion2 几乎无信号（AUROC 0.58，partial ρ 0.02），且无空间解释。本线目标：**完全不读 mask/临床标签**，
得到可解释的**稠密渗漏潜势图**，再汇聚为图像级负荷。

## 2. 方法
- 冻结 DINOv3 ConvNeXt-Tiny，stage1–3 特征上采样到 32×32 网格（C=1536，输入 512）。
- **物理先验合成反事实**：Hessian 脊线血管段作为源（扩散 σ 1.5–8）或血管邻近点状渗漏（剖面指数 κ），幅度 0.1–0.5，FOV 内；Gauss 斑块生成器作对照。
- **CDP**：逐 cell 岭回归 w·(F(I′)−F(I)) ≈ ΔI，同时惩罚滋扰视图（均值匹配整体增亮、gamma 0.8/1.2）响应 β‖w·(F(N(I))−F(I))‖²。
  λ 由训练折内留一折合成 SSE 选（无标签）。图像负荷 = FOV 内 mean / 正部 mean / top10%。
- 预测 sha256 冻结后才首次读 mask 评估。基线：强度、DoG、PatchCore 式 kNN、10-13 全局方法。
- 代码：`src/bs/physleak.py`、`scripts/physleak_{stats,fit_predict,evaluate,nested_select}.py`、`tests/test_physleak.py`（5/5 通过）。
- 产物：`/root/autodl-fs/uveitis_severity_20261013/physleak/`（主实验）与 `physleak_beta_sweep/`（β 扫描），3 seeds（42/2026/3407）。

- 生成器消融（β1, top10）：phys 0.665 > gauss 0.521 > phys+gauss 0.501；物理先验生成器是关键之一。
- 合成 R²：β0 0.994 → β10 0.906 → β100 0.779；β 呈倒 U 型，最佳 β 处合成拟合仍 >0.9。
- **嵌套选择（去后验乐观）**：外层留一折，内 4 折按面积 ρ 在 21 个 (β, 汇聚) 配置中选优，15/15 次都选 β10/pos，嵌套 pooled ρ = 0.7427/0.7556/0.7451（均值 0.748），与非嵌套一致 → 配置选择的乐观偏差可忽略。

## 4. 结论
1. 「物理先验合成反事实 + 滋扰正交」的稠密线性探针，在完全无标签的设定下首次给出稠密渗漏图（cell AUROC 0.89 vs 强度 0.81），图像级面积代理 ρ 0.748，配对显著优于先前 0.707。
2. 滋扰惩罚是决定性组件：去掉后 gamma 四分位翻转 66–70%，ρ 掉到 0.46。
3. lesion2 独立信号显著增强（partial 0.17–0.20 vs 0.02），但仍弱。

## 5. 诚实局限
- β10 与 burden_pos 是**看过 mask 指标后选的**；预注册主方法（β1/mean）只有 0.487。嵌套选择说明乐观偏差小，但正式论文仍应在新数据上把 β10/pos 作为**冻结**配置复验。
- 目标是 mask 面积代理，不是临床分级；无患者 ID，image-level bootstrap CI 可能偏窄。
- λ 总选到网格最低 1e-4，网格下界可再放宽。
- PatchCore 在全病例队列中失效（无“正常”参考），不代表其在含正常眼数据上的表现。

## 6. 下一步
- 在外部/新采集数据上冻结 β10/pos 复验；收集临床 FA 渗漏分级（如 ASOT/Tugal-Tutkun 分级）做真正的临床验证。
- 多征象图（视盘渗漏、黄斑渗漏、毛细血管渗漏分项）→ 组合成量表式评分。
- 以 CDP 稠密图为伪标签，做 Rank-N-Contrast / 有序回归轻量微调；或作为分割网络的弱监督先验。
