# 七生成器共识与假设分歧：开发结果

原生成器主方法保持不变。新候选是在已查看生成器敏感性与病灶2失败之后提出的开发实验；无掩码进入拟合，但不能称整个研究预注册或患者独立确认。[协议](severity_generator_consensus_protocol_20261013.md)固定了全部七种生成器和三种等权聚合，没有根据新结果更换权重、阈值或主方法。

## 冻结及重载范围

main与registration_group_stress旧五折共30个聚合状态、36,990条预测，全部原图与gamma条件分数及层级重载通过。70个输入校准状态哈希匹配旧生成器manifest，所有保留图像的七个输入分数和层级与旧冻结CSV一致。12,330条生成器分歧记录亦在掩码评价前冻结。

第一次程序执行因诊断字典重复`method`字段中止；当时没有写完整manifest或读取掩码。只修正冗余字段后重新执行，聚合定义及参数未改变。初次失败日志和来源哈希保存在`generator_consensus/initial_execution_note.json`，未隐藏失败。

新增4项排序/拟合集隔离/变换不匹配与退化方向拒绝/序列化不变量测试通过，与原15项同次运行共19项通过。它们验证计算性质，不能替代临床评价。

## 假设分歧

七个单位方向的Gram谱有效秩在10个scope/折状态约1.69–1.75，最大谱质量约85%。最小两方向cosine约0.335–0.374，夹角可接近70°。这里的统计对象是七个校准方向，不能与图像encoder协方差有效秩混为同一种“坍缩”诊断，也不能给方向直接命名临床征象。

2,055图中只有744图（36.20%）在七个原有校准器下得到相同四分位层级。生成器分位秩range中位0.1873，四分位区间[0.1107,0.2884]，最大0.9536；registration scope层级一致745图（36.25%）。这些是七种已测试假设的分歧，不能称概率或真实临床等级区间。

## 选择子集的对照

全部层级一致的744图中，中位聚合union rho为0.84464；原生成器在**相同744图**已经达到0.84372，配对差CI为[−0.00044,0.00245]。不一致的1,311图中原生成器rho为0.57811，中位聚合为0.58148。分歧较少的图像在此面积代理上较易排序，但选择后的高rho主要不是新聚合的增益，不能报告为整个队列或患者独立临床性能。

同旧折面积差至少0.01的355,939个依赖图像组合中，七假设严格同方向约69.94%，其正确面积方向比例为85.28%。原生成器在相同组合上的方向与七假设共同方向完全相同，因此该85.28%也是原生成器在同一子集的结果。与所有组合的79.16%比较只显示选择作用，不证明聚合分类改善。这里全部严格同向排除了分数tie；所有组合的79.16%依照既有失败审计给tie半分，补充审计逐项恢复了原correct/tie计数，避免混用计分定义。组合共享图像，不以35万组合作独立样本量。

初始评价、匹配子集对照和tie计分审计分别保存在`generator_consensus/seed42/evaluation/`与`selectivity_audit/`，来源及目标哈希均已记录。这是描述性开发证据，模型和分歧阈值没有重新拟合。
