# 完整图像自监督种子的配对事后诊断

本方案在已知seed42的SwAV/VICReg整体面积指标后制定，属于同一开发数据的事后描述，不能称预注册或独立确认。它只读取已有完整五折、冻结并通过重载审计的预测；不训练、改方向、选checkpoint或重新选择主方法。

完整报告四种共同校准器：局部合成方向、均亮度匹配方向、联合gamma方向、合成定向PC1。参考为原冻结DINO相同校准器的seed42输出；对已有相同种子的SwAV/VICReg也作配对比较。未完整五折评价的种子不进入代理性能汇总。SwAV的有序prototype没有对应VICReg分支，仍保留在原评价表，不能人为补齐。

所有记录按相同2055个uid和旧fold对齐。1000次图像bootstrap在所有方法中使用同一重采样索引，报告union Spearman差值及百分位95%区间；它不涵盖患者关联、拟合波动、开发选择或多重比较。报告五折逐折差值和改善折数，折数不是独立重复试验。

辅助指标包括病灶2存在性AUROC、病灶2阳性内部面积rho、控制病灶1面积秩及再控制亮度后的partial rho；仅作描述，不作因果或临床效力解释。同时报告相同校准器间的分数秩一致性、分位层级改变和分数唯一值数，以区别gamma稳定、不同encoder间一致性和临床稳定。这些概念不能互相替代。

读评价目标前核对每个预测文件及源码哈希、完整五折审计、评价目标哈希、全部uid与fold一致性。原评价pooled/fold指标由新脚本重算核对。全部已完成种子及不利差值均保留；原生成器和原主候选地位不变。输出位于`domain_ssl/image_ssl_comparison/`，脚本为`scripts/audit_severity_image_ssl_comparison.py`。
