# 合成校准机制控制，第三阶段

本阶段在看到第二阶段seed42相关性0.712以后准备，属于进一步方法开发，不是最初预注册实验。保持前两阶段全部结果与协议不变，不增加新图像或重新选择合成生成参数。仍未读取医生分级，评价仍不能称独立临床定级验证。

增加三个完整五折比较，在seed42/2026/3407、主分析和原近似图像stress全部执行：

1. 对原始局部增加方向进行gamma正交投影，补齐“是否均亮度匹配 × 是否gamma投影”的2×2组合。
2. 对均亮度匹配方向做固定8维随机正交子空间删除。与gamma投影匹配删除子空间秩，但不匹配实际被删除的方向范数；必须报告保留范数。
3. 将随机子空间进一步约束为保留相同方向范数。令单位原方向u、随机与u正交的单位v，gamma投影实际保留比例r。取第一删除方向 `sqrt(1-r²)*u+r*v`，另7个方向与u/v均正交；投影后范数比例精确为r。这个控制匹配投影秩和删除强度，但改变方向，不宣称符合真实采集混杂。

所有随机量只由拟合seed决定，不用真实掩码选择子空间。固定gamma特征差的无中心SVD前8维，保持L2归一化、scaler、合成剂量及拟合分位点。主问题是gamma机制是否优于同秩/同删除强度随机控制；两个随机控制各三种子，不能只保留最佳或最差一个。比较完整结果、各折及合成剂量响应、亮度鲁棒性和原图相关性，不因看到结果追加阈值或删除对照。
