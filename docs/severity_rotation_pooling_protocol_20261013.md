# 四旋转等权聚合的标签自由开发对照

本方案在完整D4压力测试发现原主候选旋转后约四分之一图像改变分位层级之后制定。既有面积代理和失败结果已知，因此这是明确的后续方法开发，不是新的患者确认性评价。原主方法及临床锁定分数保留；本轮不根据新面积结果选择seed、方法、阈值或替换主候选。

设R为256×256整数网格的逆时针90度像素置换，E为原冻结DINOv3 ConvNeXt-Tiny。固定四旋转特征均值 h(I)=1/4∑(k=0..3)E(R^k I)，在均值之后执行原L2归一化、拟合集StandardScaler、合成方向拟合、固定8维gamma子空间投影和拟合集CDF/四分位切点。四个元素在循环移位下构成相同集合，因此h(RI)=h(I)。代码先按每个坐标排序再以float64求均值，固定浮点求和次序；这只是等权平均的确定性实现，不挑选视图或权重。

对原图、gamma0.8/1.2，以及原生成器uid固定的低剂量/高剂量/均亮度匹配合成图，都分别聚合四旋转特征。合成图先用原始方位生成，再整体旋转，不在每个旋转后重新抽Gaussian场。scaler、方向、gamma子空间与阈值只使用原main拟合折的图像；每个测试图像的聚合独立于其他测试图像，不读取测试集统计。

固定执行四个原校准器：局部合成方向、均亮度匹配方向、联合gamma方向、合成定向PC1。特征均值分支执行seed42/2026/3407×五折，共60个state；这些是冻结特征下的数值/随机SVD重复，不能称新的网络训练或独立临床重复。

另固定一个简单对照：seed42原已冻结的四个校准器对四旋转特征分别给出raw投影，再等权平均raw分数。其原方向、scaler和PC1符号不变，仅用拟合图像的平均raw分数重新估计CDF及四分位切点，共20个state。它区分重新拟合旋转平均表征与直接聚合原分数；二者均按构造获得C4不变性，不把零旋转变化称为新的医学发现或充分方法创新。不同分支包含归一化及方向拟合差异，不能作单一环节的因果归因。

2189原图沿用旧缓存顺序，2055图进入旧五折评价。原图四旋转及四反射特征复用上一轮哈希核验缓存；新提取两种gamma×四旋转和三种合成图×四旋转。重新推理的五种identity条件须与原gamma/合成缓存逐元素匹配，否则停止调查。原始解码RGB哈希须匹配只读清单。FP16、batch8、原权重和原预处理保持一致，所有神经权重冻结，不运行新的领域训练。

每个分支/seed/方法保存十个条件：identity、rot90/180/270、左右反射及其后90/180/270度旋转、gamma0.8/1.2。四种分支/seed组合×四方法×2055图×十条件，共328800条预测。反射仍仅为数学控制，C4不保证反射不变；也不保证任意角度旋转、裁剪、FA时相或临床等级不变。旋转条件通过同一完整缓存orbit的循环置换评分，是结构性质核验，不是独立临床鲁棒性证据。

拟合脚本只读取图像特征、原state和既定拆分。全部state序列化后，对所有保留条件的score/raw/level重载复算至1e-12并要求层级一致；保存全部拟合/保留合成剂量响应、源码/协议/输入/状态/预测哈希，再冻结manifest。之后单独评价脚本核验冻结边界，才打开已有面积CSV。新方案在新面积结果之前固定，但开发队列先前已用于多方法选择，必须披露这一事实。

评价完整报告四方法全部种子、十条件及每折的union/lesion1/lesion2全图面积rho、lesion2存在性AUROC、分数秩一致性、层级改变和经验秩改变量。完整比较原冻结方法、直接分数平均对照和特征平均分支，不只展示联合候选。原图面积rho的配对差用1000次图像bootstrap、seed20261013，全部方法共用抽样；不将组合或种子数视为独立患者样本，不作患者关联、重拟合或多候选校正的替代。输出分位层级仍不是临床轻/中/重。

若数学不变量测试或冻结重载不通过，停止评价并保留失败日志；若代理或辅助征象变差，仍报告全部结果，不调整四旋转集合、投影维数或合成参数。群聚合属于已有通用思想，应用该操作本身不构成CCF-B论文创新性或临床有效性证明。

文献依据为Cohen与Welling的ICML2016原文（PMLR48:2990–2999），其相关工作部分明确指出对变换群平均可构造不变量：https://proceedings.mlr.press/v48/cohenc16.html 。本方案不训练其G-CNN，不把离散群均值重新命名为新架构。CVPR2016的TI-Pooling官方摘要同样讨论在变换集合上聚合表征，采用的具体网络及聚合策略与本轮固定均值不同：https://openaccess.thecvf.com/content_cvpr_2016/html/Laptev_TI-Pooling_Transformation-Invariant_Pooling_CVPR_2016_paper.html 。原始页面及Cohen全文保存在`literature/rotation_pooling/`。
