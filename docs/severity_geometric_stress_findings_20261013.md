# 冻结主候选的几何方向依赖

原DINOv3、seed42、main五折的四个校准器在完整D4方形网格变换下共生成65,760条预测，全部在打开既有面积评价CSV前冻结。重新推理2189幅原图的identity特征与原缓存最大误差为0；2055幅保留图像的20个state分数最大误差1.11×10⁻¹⁶，层级完全一致。原图解码像素哈希、各RGB通道直方图及均亮度均通过检查。推理耗时139.6秒，峰值reserved为260MiB；三个群性质/面积保持测试通过。

图像先按既定方式缩放为256×256，再以整数网格置换执行变换。没有插值、裁剪、填充或亮度改变；同样的完整网格置换保持全图掩码面积。因此本实验可以使用原全图面积目标，不需要读取、变换或改写原掩码。反射只是数学控制，可能改变解剖侧别；90度等旋转也不代表实际采集角度分布。本实验是已有结果之后的开发压力测试，不是独立临床验证。
