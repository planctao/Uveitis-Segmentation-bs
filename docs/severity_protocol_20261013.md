# 无监督 FA 炎症负担排序：首轮预设协议

本阶段目标是开发不依赖人工严重程度标签的图像表征、连续排序和候选有序分层，最终形成达到 CCF-B 投稿要求的毕业论文。首轮是探索实验，不能用图像掩码面积替代医生定级的临床验证，也不能承诺录用等级。

## 已知数据与研究边界

数据集有 2,459 幅 768×768 FA 图像，其中 270 幅 `_aug` 文件排除；2,189 幅原图来自五个旧分割折。没有可用的患者、眼别、时相或人工严重程度标签。文件编号不能证明患者独立。67 组完全相同像素的图像跨越旧折，且每组掩码字节均不相同；主分析排除这些组的全部副本，避免任意选择一个标注。必须报告近似图像候选，不能声称其分组等于患者分组。

现有两病灶标签仅保留原代码语义 `lesion1=1|3`、`lesion2=2|3`，临床名称尚未确认。绝大多数图像 lesion1 非空，缺少正常对照；正常/异常分类不适合作为主指标。单幅局部视野图像不能直接代表整只眼睛的总 ASUWOG 分数。

训练/拟合代码只能读取图像、预训练 DINOv3 权重和图像派生特征。分割 checkpoint、人工分级、掩码及掩码派生面积均不得进入特征提取、超参数选择、排序方向和分层阈值。掩码输出为独立评价文件，只在排序输出冻结后合并。此协议须在首轮掩码相关性结果计算前落盘；已有基本数据审计并不作为方法选择依据。

## 固定特征与方法

输入分析网格 256×256，DINOv3 ConvNeXt-Tiny 原始预训练 encoder 完全冻结，ImageNet 均值/标准差，strict load。不使用本项目微调过的分割 encoder。启发式有效视野为灰度>8/255的最大连通区并填洞，报告掩码落在视野外的敏感性；它不是已验证的解剖分割。

图像先验为尺度 2 与 16 像素 Gaussian 之差，在有效视野内以 MAD 标准化后大于1.5的比例，即粗尺度局部高荧光比例。它也会响应正常血管、视盘和时相，暂不称渗漏量。排序方向来自这个固定图像先验，不能用掩码面积反转排序。

固定对照：平均亮度、绝对阈值0.75的亮区比例、上述图像先验、11维形态/纹理特征的第一主成分、DINO 第一主成分、DINO 四簇 KMeans 有序输出、DINO diffusion coordinate、对图像亮度/标准差/视野比例/饱和比例 ridge residualization 后的 diffusion coordinate。主成分的符号在拟合图像中对齐图像先验；四簇按拟合先验均值排序。diffusion 使用32维 PCA、30邻居、自适应 Gaussian kernel、alpha=1 density normalization，取前6个非平凡谱坐标中与图像先验 Spearman 绝对相关最高者，再按同一先验定向；这是明确的先验选择规则，不把最大图像方差自动称为严重程度。对保留折使用 Nyström 外推，禁止将保留图像加入拟合图。

所有 scaler、PCA、ridge、图、簇及分位点只在拟合集上计算，固定 seed42。连续输出转为拟合集经验分位秩。KMeans 四簇直接输出0–3；其他方法以拟合连续分数的四分位点形成0–3候选层级，**不命名为临床轻/中/重，也不与SUN等级对应**。主分析保留旧五折、排除全部像素重复组。敏感性分析根据 dHash≤4 且64网格SSIM≥0.97的图像连接分量，额外排除与保留图像同组的拟合图像；它仍不能代替真实患者划分。

## 预定评价

主评价是各保留折连续排序与人工掩码 union 全图面积比例的 Spearman/Kendall。辅助评价包括有效视野内面积、lesion1面积、lesion2面积以及 lesion2 阳性检出AUROC。AUROC仅描述同一个标注数据集的标签2存在性，不能解读为临床严重程度。报告每折、五折均值以及汇总图像的结果，后者与前者不可混用。

固定鲁棒性扰动为灰度gamma0.8/1.2（在256网格逐通道计算、量化回8bit），模型保持冻结。报告原图/扰动排序 Spearman、候选层级改变比例；这只检验两种亮度模拟，不能证明对真实早/晚FA时相不变。另报输出与平均亮度、饱和比例、视野大小的相关性，检查是否只是采集条件排序。

bootstrap置信区间以图像为单位，固定seed20261013、1000次重采样；因为缺少患者编号，须标明区间可能过窄。不能使用QWK、分级准确率、临床AUROC或医生一致性作为已完成指标，因为独立定级标签尚不存在。所有候选和负结果保留，不按首轮结果事后修改主假设。

## 论文最终所需证据

1. 文献核对与明确研究差异；冻结特征聚类是基线，不能单独当创新。
2. 实际可复现的标签自由方法、机制消融、多种子、亮度/视野/时相混杂检验。
3. 独立医生评分或成对严重程度比较；至少两名盲法医生，报告一致性，先锁模型再评分。患者/眼别分组和整眼多视野汇总需要真实元数据。
4. 与无监督/自监督基线、面积单指标和分割辅助方案公平比较；分割辅助方案明确披露像素监督。
5. 尽可能加入外部中心、随访治疗响应和临床结局验证。无法取得时，收缩临床主张而不伪造证据。
6. 完整中文毕业论文和英文投稿稿、表图、引用、复现命令及失败分析。CCF-B具体候选会议的类别、征稿范围和当年时间须以CCF/会议官方页面另行核对。
