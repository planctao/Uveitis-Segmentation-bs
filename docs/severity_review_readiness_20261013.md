# 无监督FA排序论文的证据与投稿准备审查

本审查依据当前冻结预测、审计及实际完成实验，面向导师审阅和后续研究决策。它不代替临床专家或外部审稿意见，也不证明已经达到CCF-B录用标准。三种子领域训练及完整评价已完成；本文仍不把图像代理当作临床验证。

## 目前可以支撑的论文问题

研究对象应表述为“无人工严重程度标签的FA炎症负担排序”。当前主要贡献是揭示表征方向歧义，探索局部合成荧光校准与gamma响应投影，并通过控制、关联排除和生成器敏感性检验这套机制。代理面积相关性可报告，临床轻/中/重等级及定级准确率不可报告。

主结果为2,055图的旧折图像交叉拟合，原生成器联合候选面积rho为0.712074。registration排除后为0.712117，增加的排除只有两幅拟合图像；这说明已知关联处理影响小，不能证明患者独立。开发过程中已经查看此队列的多种方法结果，因此当前折内指标不能视为锁定方法之后的全新确认测试。

## 创新性需要进一步论证的部分

“自监督表征＋聚类＋四分位”本身难以构成充分方法创新；合成方向校准和删除干扰子空间也属于通用思路。医学场景中的可发表价值，需要来自能被独立数据检验的问题定义、明确的临床征象联系及充分的机制证据。当前较扎实的是泄漏和方向失败审计、均亮度/随机投影控制、生成器脆弱性以及不利领域学习结果。应据这些证据写出有限而可检验的结论，不能通过重新命名模块增加创新性。

VICReg是在发现SwAV表征集中之后提出的开发控制。其batch16/两个全局视图与SwAV batch8/多裁剪不同，不能把方法间差异纯归因于variance loss。完整种子结果可以说明两套明确配置的表现；如果需要识别某一损失项的因果贡献，应另预先固定匹配视图、batch及优化预算的实验，并用新确认数据评价。本轮不因部分折有效秩而调整既定队列。

三种子配对事后差值表覆盖全部共同校准器；联合VICReg相对DINO的rho差分别为−0.0728/−0.0854/−0.0346，相对SwAV为+0.1114/+0.1113/+0.3173（seed42/2026/3407）。这些图像区间不覆盖患者关联、训练和开发选择，也不能把两套配置的差值归为单项loss效果。辅助病灶2partial rho约0.0708仍需独立临床解释，见[完整种子诊断](severity_image_ssl_comparison_findings_20261013.md)。

新增完整D4几何压力测试使用原冻结主候选和三个校准器控制，共65,760条预测。主候选在任一三旋转中改变层级的图像占47.59%，任一七非identity条件中占56.45%；多数为相邻分位边界变化。该结果不支持已经获得稳定医学等级，也不支持事后挑选变换或重新锁定模型。全部条件及限定范围见[几何方向依赖](severity_geometric_stress_findings_20261013.md)。

四旋转聚合对照完整报告了特征均值三数值种子及简单原raw分数均值。联合特征均值未提高面积rho，分数均值只有小开发差异；三种子没有重新训练encoder。Cohen与Welling的原文确认群平均是通用既有技术，不能据此主张充分创新。详见[旋转聚合报告](severity_rotation_pooling_findings_20261013.md)。

## 需要真实临床数据才能推进的工作

患者、眼别、成像时相、设备和视野信息需要从数据来源取得，不能从文件格式或配准分量中推断。本地仅原图lesion1非空数已超过相同总图数论文的血管渗漏阳性数，标签定义及注释版本不能由数量相同推定，详见[来源核对](severity_clinical_sign_provenance_20261013.md)。独立医生应先确认两类掩码的临床含义及评分rubric，再依锁定分析计划独立判读。已经准备的200图/100配对仍来自开发队列，空模板不是医生评分，也不是外部验证。

确认性评价至少需要真实患者隔离，并尽可能采用新中心或独立病例。FA多时相与多视野通常对应整眼评分，单图面积和纵向活动变化须分开定义。取得新数据后，在评分开放前锁定候选方向、绝对/相对输出定义及统计终点；若使用医生标签调参，应明确披露监督使用，保留最终患者级测试集。

本轮完整检查2189幅原图的标准文件头，未观察到候选临床EXIF字段；空白19字段模板不是恢复出的患者表。血管炎评分全文明确区分血管渗漏活动度与闭塞损伤，并依赖中央/周边位置、象限和真实时间扩展。单图面积排序不能直接套用该WFFA整眼规则；rubric仍待医生确认，详见[临床终点证据补充](severity_clinical_rubric_evidence_20261013.md)。这两份补充报告尚未加入当前26页论文正文，原导出和视觉审查记录保持对应原稿。
