# 三种子图像自监督完整评价及配对事后诊断

三种子（42、2026、3407）均训练到固定20epoch，并完成五折冻结重载与全量分数重算。每个VICReg seed有24,660条预测、每个SwAV seed有30,825条预测；每种子全部最终神经encoder/projection通过指定原图batch重载核验，缓存分数覆盖全部保留预测，最大经验秩误差1.11×10⁻¹⁶。三种子任务在训练前固定，未按代理结果调整配置、挑选checkpoint或选择seed。神经网络重载是抽样batch核验，缓存分数重载覆盖全部保留预测；二者范围不同。

## 病灶2与表征几何

VICReg联合方向在228幅病灶2阳性图像内部的病灶2面积rho为0.387825；控制病灶1秩后partial病灶2rho为0.070824，再控制亮度为0.075239。原DINO同main输出对应0.349116/0.019491/0.023545。条件秩相关是描述性残差相关，不是因果效应；局部标签临床映射尚未确认，不能据这些变化声称临床获益。

VICReg五折encoder raw covariance有效秩15.75–21.89，projection为38.55–40.95，encoder坐标std为匹配原DINO的1.790–1.988倍。原DINO有效秩27.86–28.75，SwAV为1.49–2.67。VICReg分散程度更高，但联合面积排序仍低于冻结主候选；有效秩不是炎症语义或医学优劣的充分指标。增强批量投影std约0.6888–0.6953，与原图encoder std不同，有限批量loss取舍另见[解析核对](severity_vicreg_batch_geometry_20261013.md)。

新脚本逐项复算了三种子SwAV/VICReg及冻结DINO的共同校准输出和对应逐折面积rho、病灶2AUROC，均匹配各自冻结评价至1e−12。完整输出和输入/源码/结果哈希位于`domain_ssl/image_ssl_comparison/`。最初执行因误写层级范围1–4而在读取评价CSV前停止，随后只修正为项目已有0–3编码；失败日志及来源哈希保留。原训练、预测和主方法未修改。
