# 分类实验记录归档

- protocols/ 保存各固定研究拟合前的协议及归档时状态，按研究名称分目录。
- preflight/ 保存各结构、梯度、CUDA 首批和推理等预检 JSON。
- continuous_search/ 是运行中搜索的状态和排行榜快照，不是搜索全部模型文件。
- legacy_binary/ 保存早期二分类与细病种分类的汇总结果。
- 三分类汇总 JSON 保存在 ../threeclass/results/，保留原有相对布局。除清单中明确登记的逐患者列表省略外，保留原文件字节，便于核对来源与哈希。

STUDY_INDEX.md 仅从已归档的 comparison.json 生成，便于查找各研究的开发指标和确认结论。未归档原始医疗图像、逐图/逐患者预测、患者清单、模型和特征二进制。历史记录中指向这些文件的路径和哈希属于来源说明，需要原实验存储才能恢复相应审计或推理。
