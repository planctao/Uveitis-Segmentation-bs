## 当前开发参考 M8

M8 使用冻结 DINOv3-B/L Backbone、320/448 双尺度及三个各含 3 个种子的 MLP 分支：

`P = 0.1875 × 原始B + 0.5625 × 正常参考B + 0.25 × 寄存器增强正常L`

正常参考投影只使用拟合部分正常患者估计 PCA32。新 L 分支使用原 MLP 隐藏向量作为查询，对 4 个预训练 register token 做注意力池化，并经零初始化残差读出。该结构使用已有注意力和集成原则，不声称方法首创。

| 开发指标 | M8 |
|---|---:|
| 验证集准确率，374 张 | 89.84% |
| 验证集 Macro-F1 | 0.89479 |
| 原患者三折平均 Macro-F1 | 0.83901 |

候选按原开发门槛选定并冻结，再使用此前未用的两组患者三折划分复验。每折重新训练所有比较分支，并在折内估计预处理及正常空间。

| 同一组新患者六折 | 平均准确率 | 平均 Macro-F1 |
|---|---:|---:|
| M8 | 82.21% | 0.82889 |
| M7 | 81.89% | 0.82589 |
| M6 | 80.90% | 0.81406 |
| M5 | 78.83% | 0.78940 |
| 固定 Gaussian 参考 | 79.07% | 0.79223 |

相对 M7 的配对患者 Macro-F1 差值 95% 区间为 `[0.000454, 0.005579]`；相对其余三个参考的区间下界也均为正，满足预声明门槛。配对区间基于合并的重复预测计算，与表中的逐折指标平均定义不同。

复验来自开发患者的新划分，未包含全部历史选型及训练不确定性。M8 尚未进行外部队列评估，不能把其开发准确率与上述两阶段外部准确率直接比较。

## 推理与核查

在项目目录运行：

```bash
env OMP_NUM_THREADS=4 OPENBLAS_NUM_THREADS=4 MKL_NUM_THREADS=4 NUMEXPR_NUM_THREADS=4 \
  python predict_register_blend.py --image /绝对路径/图像.jpg
```

输出感染、非感染、正常三类概率。9 个打包模型与开发来源字节一致；374 张验证图的预测独立恢复；原图/缓存推理、命令行及额外 6 张图的 B/L 和寄存器特征均已核对。

FP16 单张与三张批处理在核查的 6 张图上最大概率差为 0.001266、平均为 0.000294，类别决定一致。CLI 与相同批大小的单张 API 概率完全一致，原始失败检查与补充验证协议均保留。
